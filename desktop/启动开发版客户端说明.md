对，`npm run dev` 只启动 **renderer 的 Web 预览版**，不是 Electron 客户端。它能看界面，但没有 Electron preload、IPC、文件选择器、真实 Python worker，所以设置页、输出页、登录态等都可能和安装版客户端不一致。

以后本地调试客户端，按这个流程走。

**正确启动方式**

先开第一个 PowerShell，启动 Vite renderer：

```
cd D:\AiCode\feedgrab\desktop
& 'D:\nodejs\npm.cmd' run dev -- --host 127.0.0.1
```

看到类似这个就保持窗口不要关：

```
Local: http://127.0.0.1:5173/
```

再开第二个 PowerShell，启动 Electron 客户端：

```
cd D:\AiCode\feedgrab\desktop

$env:ELECTRON_RENDERER_URL = "http://127.0.0.1:5173/"
$env:FEEDGRAB_DESKTOP_MOCK = ""

& .\node_modules\.bin\electron.cmd .
```

注意：不要用浏览器打开 `http://127.0.0.1:5173/` 来判断客户端行为。真正要看的，是第二个命令打开的 **feedgrab Desktop Electron 窗口**。

**怎么确认你启动的是客户端**

在 Electron 客户端里：

- 顶部窗口标题是 `feedgrab Desktop`
- 抓取页日志应显示 `Python sidecar worker 已连接`
- 文件选择、打开输出路径、读取真实登录态、Python worker 调用才是客户端真实行为

如果你看到：

```
浏览器测试 mock worker 已连接。
```

那就是 Web/mock 预览，不是客户端真实运行环境。

**什么时候需要重新 build**

只改 React 页面或 CSS：

```
# 不需要 build，Vite 会热更新
```

改了这些文件就需要先 build，再重启 Electron：

```
desktop/electron/*
desktop/vite.config.ts
desktop/package.json
```

命令：

```
cd D:\AiCode\feedgrab\desktop
& 'D:\nodejs\npm.cmd' run build
```

然后再重新跑 Electron 启动命令。

**今天调试建议**

我们接下来统一以 Electron 开发客户端为准调试。Web 版可以保留为“界面预览”，但它的数据和能力必须尽量 fallback 到接近客户端，不能再出现只剩 Discourse、输出卡片异常这种误导性差异。等客户端和 Web 预览都稳定后，再重新打包安装版。
